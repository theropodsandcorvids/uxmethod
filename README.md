Put it on GitHub Pages (about 10 minutes, all in your web browser)
1. Double-click the zip to unzip it. You'll get a folder named UNM-LA_Grants_Portfolio.
2. Go to github.com and sign up or sign in. A free account works.
3. Click the + at the top right, then New repository.
4. Name it something like unm-la-grants-portfolio. Choose Public, because free accounts can only publish public repositories. Leave everything else as it is and click Create repository.
5. On the next page, click the uploading an existing file link.
6. Open the unzipped folder in Finder and select everything inside it: the 7 .html files, the documents folder and README.txt. Drag them all into the browser window. Drag the folder's contents, not the folder itself, so index.htmlends up at the top level.
7. Wait until all the files are listed, including documents/…. Then scroll down and click Commit changes.
8. Go to the repository's Settings tab, then Pages in the left menu.
9. Under Build and deployment, set Source to Deploy from a branch. Set Branch to main and the folder to / (root), then click Save.
10. Wait 1–2 minutes and refresh the page. A box at the top will show your site address, for example https://yourname.github.io/unm-la-grants-portfolio/. Click Visit site.
11. Check that it works: open the Sample Proposal page, type in a field and click Download. The PDF should have your text in it.


To update it later: open the repository, click Add file → Upload files, drag in the new files and commit. Files with the same name get replaced. The live site updates in a minute or two.

Keep in mind: a public site can be seen by anyone who has the link, so only include material that's fine to share. The PDF viewer loads from the internet (jsdelivr.net), so it needs a connection.
